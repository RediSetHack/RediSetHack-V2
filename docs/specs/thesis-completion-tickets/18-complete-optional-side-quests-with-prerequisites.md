## What to build

Learners discover an optional objective, understand its prerequisites, complete its designated activity, and receive one Side Quest accomplishment.

## Acceptance criteria

- [ ] Keep Side Quest distinct from existing multiple-choice Quest; reuse an existing assessed activity for the first objective.
- [ ] Support prerequisite clauses for numeric Level/Adventurer Rank, earned Badge, Novel completion, and prior activity/challenge completion; unknown skill estimates deny skill-gated access until mastery integration.
- [ ] Apply eligibility to listing details, start, submit, and completion; persist completion/XP/event identity and return actionable lock reasons.
- [ ] Deliver a minimal optional-objective list/detail and prove unlocking, direct-route rejection, repeat/replay handling, and non-blocking main-story behavior.
- [ ] Keep the slice demonstrable through its actual learner/contributor interface or existing administration/research operation; update affected contracts and use the approved behavioral test boundaries.
