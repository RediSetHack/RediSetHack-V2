## What to build

Learners browse and filter approved Novels and activities by topic, competency, and difficulty while seeing eligibility reasons.

## Acceptance criteria

- [ ] Add bounded search/filter results using existing catalog data and approved content versions; include interest/topic metadata only as needed.
- [ ] Apply publication and visibility policy consistently, returning safe locked metadata without restricted content.
- [ ] Use a small discovery interface integrated with current navigation, with useful empty/error states and accessible controls.
- [ ] Prove draft/rejected/retired content cannot appear or be fetched via alternative discovery paths and filters return the intended content.
- [ ] Keep the slice demonstrable through its actual learner/contributor interface or existing administration/research operation; update affected contracts and use the approved behavioral test boundaries.
